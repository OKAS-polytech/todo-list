# セットアップと実行の手順書

このドキュメントは、TODOリストアプリケーション（CUI版・GUI版）を実行するための手順を説明します。

## ステップ1: SQLite JDBCドライバの準備

このアプリケーションは、動作するためにSQLiteデータベースのライブラリ（JDBCドライバ）が必要です。

1.  **ドライバのダウンロード**
    以下のリンクから、`sqlite-jdbc-....jar` という名前のファイルをダウンロードしてください。

    *   **[SQLite JDBC Driver ダウンロードページ (Maven Central)](https://repo1.maven.org/maven2/org/xerial/sqlite-jdbc/)**

    (推奨バージョン: `3.46.0.0` 以降)

2.  **`lib`フォルダの作成と配置**
    ダウンロードしたJARファイルを、プロジェクトのルートディレクトリに作成した `lib` フォルダの中に配置してください。最終的なフォルダ構成は以下のようになります。

    ```
    todolist-project/
    ├── dist/
    │   ├── todolist-cui.jar
    │   └── todolist-gui.jar
    ├── lib/
    │   └── sqlite-jdbc-3.46.0.0.jar  <-- ダウンロードしたファイルをここに置く
    └── ... (その他のプロジェクトファイル)
    ```

    **重要:** `dist` フォルダと `lib` フォルダが、上記のように同じ階層に並んでいる必要があります。

## ステップ2: アプリケーションの実行

コマンドプロンプト（またはターミナル）を開き、プロジェクトのルートディレクトリ（`todolist-project/`）に移動してから、以下のコマンドを実行してください。

### CUI版の実行

コンソール（黒い画面）で操作するバージョンです。

```bash
java -jar dist/todolist-cui.jar
```

### GUI版の実行

ウィンドウ画面で操作するバージョンです。

```bash
java -jar dist/todolist-gui.jar
```

コマンドを実行すると、それぞれCUIまたはGUIのTODOリストアプリケーションが起動します。アプリケーションのデータは、コマンドを実行したディレクトリに `todolist.db` という名前のファイルで自動的に保存されます。
