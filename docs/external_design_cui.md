# CUI版TODOリストアプリケーション 外部設計書

## 1. 概要
本文書は、CUI（Command-line User Interface）版TODOリストアプリケーションの外部設計を定義するものである。ユーザーとシステムの対話方法、画面表示、操作コマンドについて記述する。

## 2. 画面設計
本アプリケーションは、標準入出力を利用したCUIで操作を行う。

### 2.1. 起動時画面
アプリケーションを起動すると、ウェルカムメッセージとコマンドプロンプトが表示される。

```
Todoリストアプリケーションへようこそ！
コマンドを入力してください (add, list, done, delete, memo, exit):
>
```

### 2.2. タスク一覧表示
`list` コマンド実行時、登録されているタスクが以下の形式で一覧表示される。

**タスクが存在する場合:**
```
--- TODOリスト ---
ID: 1, 内容: 設計書を作成する, 状態: [未完了] (メモあり)
    └ メモ: 先に要件定義をFIXさせること。
ID: 2, 内容: 実装を行う, 状態: [完了]
------------------
```

**タスクが存在しない場合:**
```
--- TODOリスト ---
(タスクはありません)
------------------
```

## 3. コマンド仕様
ユーザーはプロンプト `>` の後、以下のコマンドを入力して操作を行う。

### 3.1. `add "<タスク内容>" ["<メモ内容>"]`
新しいタスクを追加する。メモは任意。
- 引数はダブルクォーテーションで囲む必要がある。

**例:**
```
> add "新機能のアイデアを出す" "ブレインストーミングの結果をまとめる"
タスクを追加しました。
> add "定例会議"
タスクを追加しました。
```

### 3.2. `list`
登録されているすべてのタスクを一覧表示する。

### 3.3. `done <タスクID>`
指定されたIDのタスクを完了状態にする。

**例:** `> done 1`

### 3.4. `delete <タスクID>`
指定されたIDのタスクを削除する。

**例:** `> delete 2`

### 3.5. `memo <タスクID> "<新しいメモ>"`
指定されたIDのタスクのメモを更新（上書き）する。

**例:** `> memo 1 "要件定義がFIXした"`

### 3.6. `exit`
アプリケーションを終了する。

## 4. エラーハンドリング
- 不正なコマンドや引数が入力された場合、適切なエラーメッセージを表示する。
- 存在しないタスクIDが指定された場合、「エラー: 指定されたIDのタスクは存在しません。」と表示される。
