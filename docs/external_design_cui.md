# CUI版TODOリストアプリケーション 外部設計書

## 1. 概要
本文書は、CUI（Command-line User Interface）版TODOリストアプリケーションの外部設計を定義するものである。ユーザーとシステムの対話方法、画面表示、操作コマンドについて記述する。

## 2. 画面設計
本アプリケーションは、標準入出力を利用したCUIで操作を行う。

### 2.1. 起動時画面
アプリケーションを起動すると、ウェルカムメッセージとコマンドプロンプトが表示される。

```
Todoリストアプリケーションへようこそ！
コマンドを入力してください (add, list, done, delete, exit):
>
```

### 2.2. タスク一覧表示
`list` コマンド実行時、登録されているタスクが以下の形式で一覧表示される。

**タスクが存在する場合:**
```
--- TODOリスト ---
ID: 1, 内容: 設計書を作成する, 状態: [未完了]
ID: 2, 内容: 実装を行う, 状態: [完了]
------------------
```

**タスクが存在しない場合:**
```
--- TODOリスト ---
(タスクはありません)
------------------
```

## 3. コマンド仕様
ユーザーはプロンプト `>` の後、以下のコマンドを入力して操作を行う。

### 3.1. `add <タスク内容>`
新しいタスクを追加する。
- `<タスク内容>` には、追加したいタスクの説明を記述する。
- 実行後、「タスクを追加しました。」というメッセージが表示される。

**例:**
```
> add 新機能のアイデアを出す
タスクを追加しました。
```

### 3.2. `list`
登録されているすべてのタスクを一覧表示する。
- 詳細は「2.2. タスク一覧表示」を参照。

### 3.3. `done <タスクID>`
指定されたIDのタスクを完了状態にする。
- `<タスクID>` には、完了したいタスクのID（数値）を指定する。
- 実行後、「タスク(ID: X)を完了しました。」というメッセージが表示される。
- 存在しないIDが指定された場合、「エラー: 指定されたIDのタスクは存在しません。」と表示される。

**例:**
```
> done 1
タスク(ID: 1)を完了しました。
```

### 3.4. `delete <タスクID>`
指定されたIDのタスクを削除する。
- `<タスクID>` には、削除したいタスクのID（数値）を指定する。
- 実行後、「タスク(ID: X)を削除しました。」というメッセージが表示される。
- 存在しないIDが指定された場合、「エラー: 指定されたIDのタスクは存在しません。」と表示される。

**例:**
```
> delete 2
タスク(ID: 2)を削除しました。
```

### 3.5. `exit`
アプリケーションを終了する。
- 「アプリケーションを終了します。」というメッセージが表示され、プログラムが終了する。

## 4. エラーハンドリング
- 不正なコマンドが入力された場合、「エラー: 不正なコマンドです。」と表示される。
- コマンドの引数が不正な場合（例: `done` コマンドでIDが指定されない、IDが数値でない）、適切なエラーメッセージを表示する。
