# GUI版TODOリストアプリケーション 外部設計書

## 1. 概要
本文書は、GUI（Graphical User Interface）版TODOリストアプリケーションの外部設計を定義するものである。画面レイアウト、UIコンポーネント、およびユーザー操作について記述する。

## 2. 画面設計
アプリケーションは単一のウィンドウで構成され、上下に分割されたレイアウトを持つ。

- **上部**: タスク入力エリアとタスク一覧表示エリア
- **下部**: 選択したタスクのメモ表示・編集エリア

### 2.1. UIコンポーネント詳細

#### 2.1.1. タスク入力エリア (ウィンドウ最上部)
- **テキストフィールド (`JTextField`)**: 新しいタスクの内容を入力する。
- **追加ボタン (`JButton`)**: テキストフィールドの内容をタスクとして追加する。

#### 2.1.2. タスク一覧表示エリア (ウィンドウ中央上部)
- **スクロール可能なリスト (`JList`)**: 登録されているタスクを一覧表示する。
  - 各タスクは `[状態] タスク内容 (メモあり)` の形式で表示される。
  - ユーザーはリストから一つのタスクを選択できる。

#### 2.1.3. メモ表示・編集エリア (ウィンドウ中央下部)
- **タイトル付きテキストエリア (`JTextArea`)**:
  - ラベル: "メモ"
  - 選択されたタスクのメモが表示され、編集も可能。
- **メモ保存ボタン (`JButton`)**:
  - ラベル: "メモ保存"
  - テキストエリアの内容を、選択されているタスクのメモとして保存する。

#### 2.1.4. 操作ボタンエリア (ウィンドウ最下部)
- **完了ボタン (`JButton`)**: 選択されているタスクを完了状態にする。
- **削除ボタン (`JButton`)**: 選択されているタスクを削除する。

## 3. ユーザー操作フロー

### 3.1. タスクの追加
1.  ユーザーはテキストフィールドにタスク内容を入力し、"追加"ボタンをクリックする。
2.  システムはタスクを（メモなしで）リストに追加し、データベースに保存する。
3.  タスク一覧の表示が更新される。

### 3.2. タスクの完了
1.  ユーザーはリストからタスクを選択する。
2.  "選択したタスクを完了"ボタンをクリックする。
3.  システムはタスクの状態を「完了」に変更し、データベースと画面表示を更新する。

### 3.3. タスクのメモを編集する
1.  ユーザーはリストからタスクを選択する。
2.  システムのメモエリアにそのタスクのメモが表示される。
3.  ユーザーはメモエリアのテキストを編集する。
4.  "メモ保存"ボタンをクリックする。
5.  システムは編集内容をデータベースに保存し、タスク一覧の表示を更新する（"(メモあり)"表示のため）。

### 3.4. タスクの削除
1.  ユーザーはリストからタスクを選択する。
2.  "選択したタスクを削除"ボタンをクリックする。
3.  確認ダイアログが表示され、"はい"を選択すると、システムはタスクをデータベースから削除し、画面表示を更新する。
