# GUI版TODOリストアプリケーション 外部設計書

## 1. 概要
本文書は、GUI（Graphical User Interface）版TODOリストアプリケーションの外部設計を定義するものである。画面レイアウト、UIコンポーネント、およびユーザー操作について記述する。

## 2. 画面設計
アプリケーションは単一のウィンドウ（JFrame）で構成される。ウィンドウは主に3つのエリアに分かれる。

- **上部**: タスク入力エリア
- **中部**: タスク表示エリア
- **下部**: 操作ボタンエリア

### 2.1. ウィンドウ全体
- **タイトル**: "TODO List"
- **サイズ**: 幅500px, 高さ400px程度（リサイズ可能）
- **終了動作**: ウィンドウを閉じるとアプリケーションが終了する。

### 2.2. UIコンポーネント詳細

#### 2.2.1. タスク入力エリア
- **テキストフィールド (`JTextField`)**:
  - ユーザーが新しいタスクの内容を入力するためのフィールド。
  - 幅はウィンドウの幅に合わせて広がる。
- **追加ボタン (`JButton`)**:
  - ラベル: "追加"
  - テキストフィールドの右側に配置される。
  - クリックすると、テキストフィールドの内容が新しいタスクとしてリストに追加される。

#### 2.2.2. タスク表示エリア
- **スクロール可能なリスト (`JList` in `JScrollPane`)**:
  - 登録されているタスクが一覧表示される。
  - 各タスクは、`[状態] タスク内容` の形式で表示される (例: `[完了] 設計書をレビューする`)。
  - ユーザーはリストの中から一つ以上のタスクを選択できる。
  - タスクがリストの表示領域を超える場合は、縦スクロールバーが表示される。

#### 2.2.3. 操作ボタンエリア
- **完了ボタン (`JButton`)**:
  - ラベル: "完了"
  - クリックすると、タスク表示エリアで選択されているタスクが完了状態になる。
  - 完了済みのタスクを選択してクリックしても状態は変わらない。
- **削除ボタン (`JButton`)**:
  - ラベル: "削除"
  - クリックすると、タスク表示エリアで選択されているタスクがリストから削除される。

## 3. ユーザー操作フロー

### 3.1. タスクの追加
1.  ユーザーは「タスク入力エリア」のテキストフィールドにタスク内容を入力する。
2.  "追加"ボタンをクリックする。
3.  システムはタスクをリストに追加し、「タスク表示エリア」の表示を更新する。
4.  テキストフィールドは空になる。

### 3.2. タスクの完了
1.  ユーザーは「タスク表示エリア」のリストから、完了したい未完了のタスクを一つ以上選択する。
2.  "完了"ボタンをクリックする。
3.  システムは選択されたタスクの状態を「完了」に変更し、リストの表示を更新する。

### 3.3. タスクの削除
1.  ユーザーは「タスク表示エリア」のリストから、削除したいタスクを一つ以上選択する。
2.  "削除"ボタンをクリックする。
3.  システムは選択されたタスクをリストから削除し、リストの表示を更新する。
