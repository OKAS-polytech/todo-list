# TODOリストアプリケーション 要件定義書

## 1. 概要
本ドキュメントは、CUI、GUI、Webの3つのインターフェースで動作するTODOリストアプリケーションの要件を定義するものである。
本プロジェクトでは、まずCUIアプリケーションの開発から着手し、その核となるビジネスロジックを実装する。

## 2. 目的
ユーザーが日々のタスクを効率的に管理できるように支援することを目的とする。

## 3. 機能要件
ユーザーは以下の機能を利用できるものとする。

### 3.1. タスクの追加 (Create)
- ユーザーは新しいタスクをリストに追加できる。
- タスクには、内容（文字列）の情報が含まれる。
- 追加されたタスクは「未完了」状態となる。

### 3.2. タスクの一覧表示 (Read)
- ユーザーはリストに含まれるすべてのタスクを一覧で確認できる。
- 一覧表示では、各タスクに一意のID、内容、完了状態（完了/未完了）が表示される。

### 3.3. タスクの完了 (Update)
- ユーザーはIDを指定して、特定のタスクを「完了」状態に変更できる。
- 既に完了状態のタスクを再度完了にしようとした場合、その旨をユーザーに通知する（エラーにはしない）。

### 3.4. タスクの削除 (Delete)
- ユーザーはIDを指定して、特定のタスクをリストから削除できる。

### 3.5. アプリケーションの終了
- ユーザーは明示的にアプリケーションを終了させることができる。

## 4. 非機能要件
### 4.1. 永続化
- CUI版の初期実装では、データの永続化は行わない。アプリケーションを終了すると、作成したタスクリストは失われる。

### 4.2. プラットフォーム
- Javaが動作する環境であれば、どのOSでも動作すること。
